# Instructor manager Schedule Dashboard

A responsive dashboard that allows instructors to view the schedules of available Instructor support managers across different learning studios.

## Screenshot

![Project Screenshot](./images/screenshot.png)

## Features

- View instructor support manager schedules
- Search for specific instructor support managers
- View studio contact information
- Responsive design of app. Mobile, tablet, and desktop layouts

## Technologies

- HTML
- Tailwind CSS
- JavaScript

## What I Learned

While building this project, I practiced:

- Building responsive layouts with Tailwind CSS
- Using Flexbox
- Creating reusable UI components using templates
- Working with JavaScript
- Implementing search functionality
